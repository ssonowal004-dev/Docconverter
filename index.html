Frequently Asked Questions
Is DocConverter really free? ▼
Yes, completely free. There are no hidden fees, no watermarks, no sign-up requirements, and no file size tricks. Every tool listed on this page works for free.
Are my files uploaded to a server? ▼
No. All processing happens entirely inside your web browser using JavaScript libraries. Your files are never sent to any server and never leave your device. This makes DocConverter safe to use for confidential documents.
What file formats are supported? ▼
DocConverter supports PDF, DOCX (Word), XLSX (Excel), PPTX (PowerPoint), JPG, PNG, WebP, and GIF. You can convert between these formats in many combinations using the tools above.
Does it work on mobile devices? ▼
Yes! DocConverter works in any modern web browser including Safari on iPhone and iPad, Chrome on Android, and all desktop browsers. No app installation is needed.
Why does the tool need an internet connection? ▼
The JavaScript conversion libraries (pdf.js, pdf-lib, mammoth.js etc.) are loaded from a CDN the first time you use the tool. After they're cached in your browser, many tools will work offline. Your actual files are never sent over the internet.
